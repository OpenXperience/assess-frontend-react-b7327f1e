# React + Vite

This project provides a minimal Vite React setup for the login form component.

## Build a Login Form Component

`LoginForm` renders an email field, a password field, and a submit button.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## How to submit

1. Build it, committing as you go — small commits, clear messages.
2. Push the branch with `git push -u origin <branch>`.
3. Open a pull request and paste its URL back into OpenExp.

The checks run automatically when you open the pull request.
